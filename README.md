# Heart & Home Manager for Android

A simple private-dashboard launcher for the owner of Heart & Home cleaning services. Developed by **Trio Minds Digital**.

### Install on Android

1. Open [Latest Heart & Home Manager Release](https://github.com/Blackcode-cmd/heart-home-manager-downloads/releases/latest) on your Android phone.
2. Download the APK file named **Heart-and-Home-Manager.apk** under Assets.
3. Open the downloaded file using Chrome or Files. Android may request one-time permission to install from that source. Only allow it if you trust this official release page.
4. After installation, tap the **Heart & Home Manager** flower icon, then **Open My Dashboard**.
5. Sign in to the private dashboard using your approved Google account. Do not share your password.

### What the app does

The Android app opens the secure, online Heart & Home dashboard, allowing the owner to review incoming website cleaning requests and update approved cleaning prices and information. Browser sign-in supports Google's security flow. The app does not read your SMS, calls, contacts, photos, or regular Gmail.

Changes made to the website and dashboard automatically appear when you open or refresh the manager, without needing another APK. When the Android launcher itself changes, an updated signed APK will appear in [Releases](https://github.com/Blackcode-cmd/heart-home-manager-downloads/releases). Download and install the newer version over the existing app; Android verifies it was signed by the same developer key.

**Requires internet; Android 8.0+; no special Android permissions.** Installation is not available through Google Play. Android may warn that APKs downloaded outside an app store require caution; do not disable Play Protect.
